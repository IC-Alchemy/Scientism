# Generation of transmissible HCV virions from a molecular clone (Hong et al. 1999)

## Source type
- Role in this vault: transmissible molecular-clone rung for [[synthesis/hepatitis-c-hepatitis-c-virus-evidence-ladder]] — one of the named acquisition gaps, now at abstract level
- Journal/year: *Virology*, 1999
- Source basis in hand: PubMed abstract; full text not obtained

## Evidence fields
| Field | Extraction |
|---|---|
| Study type | Molecular-clone construction with in-vivo infectivity testing and a transmission pass |
| Subject / sample | Chimpanzees: one for direct intrahepatic RNA inoculation, one naive animal for the serum-transmission pass |
| Intervention or exposure | Intrahepatic inoculation of in-vitro-transcribed RNA from a consensus-repaired H77-derived clone (22 nonconsensus mutations systematically repaired); intravenous injection of the first animal's serum into a naive chimpanzee |
| Comparator / control | Prior failed clone attempts as the implicit comparator (the paper explains earlier failures via nonconsensus mutations); sequence comparison against Kolykhalov 1997 and Yanagi 1997 clones |
| Endpoint | HCV positivity over time; hepatitis development; transmission to the second animal |
| Result | The repaired consensus clone yielded infectious virions after direct intrahepatic RNA inoculation: the RNA-infected chimpanzee developed hepatitis and remained HCV-positive beyond 11 months. Serum from this animal transmitted HCV infection to a second naive chimpanzee, which the authors present as validating infectivity of the repaired clone. The repaired clone had 4 amino-acid mismatches with the Kolykhalov clone and 8 with the Yanagi clone (43 and 67 RNA-level mismatches, mostly synonymous). |
| Main limitation | Abstract-level record; n = 1 per step; direct intrahepatic RNA transfection is an artificial route; hepatitis grading and viral-titer curves need the text. |

## What the abstract can answer
- Whether RNA alone from a repaired molecular clone, without any passaged virus, can initiate infection that is then transmissible by serum to a second animal: yes in this record — the transmissible-virion rung.
- That clone sequence fidelity was a live variable in earlier failed attempts, dovetailing with the vault's existing Yanagi 1997 boundary record.

## What full text would still need to establish
- Viral kinetics, hepatitis histology, and the second animal's follow-up detail.

## Later inferential-leap risk
The ladder's boundary applies: intrahepatic RNA transfection plus a serum pass demonstrates molecular infectivity in chimpanzees, not ordinary human transmission, and not that every HCV-negative/negative-assay boundary case is explained by clone defects.

## Vault conclusion
Abstract-level: a consensus-repaired H77 molecular clone's RNA initiated HCV infection with hepatitis in a chimpanzee, and its serum transmitted infection to a second naive animal — a transmissible-virion record at abstract level.
